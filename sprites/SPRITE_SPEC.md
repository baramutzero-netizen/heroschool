# 캐릭터 스프라이트 제작 규칙 v3

## 기본 원칙

**시트를 먼저 그리지 않고, 독립된 프레임을 완성한 후 묶습니다.**
이미 붙어 있는 시트를 균등 분할하면 몸·무기·효과가 옆 칸으로 잘려 넘어갑니다.
새 작업은 아래 규격의 개별 PNG 또는 레이어가 있는 Aseprite 파일로 제작합니다.

| 항목 | 규격 |
|---|---|
| 작업 캔버스 | 모든 프레임 256×256px |
| 지면 기준점 / 피봇 | x=128, y=170 |
| 안전 여백 | 네 변에서 최소 16px, 그림은 [16,240) 안쪽 |
| 게임 내 배치 공간 | 기존 128×128 유지; 추가 여백은 공간 밖에 투명하게 표시 |
| 캐릭터 크기 | 기본 자세 약 96px 높이. 무기·효과를 포함한 외곽으로 매번 맞추지 않음 |
| 방향 | 오른쪽 기준. 상대 팀은 같은 피봇을 중심으로 좌우 반전 |
| 형식 | 투명 PNG RGBA, 알파 0 또는 255, 픽셀 확대 시 보간 끄기 |

기존 128px 좌표 (64,106)에 위·아래·좌·우로 64px씩 공간을 더한 규격입니다.
캔버스가 커져도 캐릭터 몸을 두 배로 확대하지 않습니다.

## 포즈와 기준점

1. 먼저 기본 자세의 머리 크기·몸 비율·발 위치를 확정합니다.
2. 모든 모션에서 같은 크기와 같은 원점으로 그립니다. 프레임마다 자동 중앙 정렬/자동 크기 맞춤을 금지합니다.
3. 점프·돌진·뒤로 밀림은 원점에 대한 의도적인 이동으로 표현합니다. 발을 매번 지면으로 끌어내리지 않습니다.
4. 팔·몸통·무기의 연결을 확인합니다. 최대 공격 포즈부터 공간을 확보하고 준비→공격→회수 순서를 채웁니다.
5. 공격이 안전 영역을 넘으면 투사체/검기/긴 마법 효과를 별도 효과 레이어로 옮깁니다. 인물을 작게 줄여 해결하지 않습니다.
6. 긴 투사체와 화면 전체 효과는 게임의 전투 효과 계층에서 움직입니다. 캐릭터 프레임에는 손 주변의 작은 효과만 남깁니다.

## 모션

| 행 | 파일 접두사 | 권장 프레임 | 재생 |
|---|---|---|---|
| 0 | idle | 2–4 | 반복 |
| 1 | attack | 4–6 | 준비→발동→회수, 전투 상태가 끝나면 기본 자세 |
| 2 | hit | 2–3 | 피격→복귀 |
| 3 | down | 3–5 | 마지막 프레임 유지 |
| 4 | win | 3–4 | 반복 |

현재 이관본은 직업당 4/6/3/5/4, 총 22프레임입니다.
프레임 시간은 manifest에 명시합니다. 전투에서는 기존 재생 속도에 맞춰 비율을 조정합니다.
투명한 몸 프레임도 효과가 있으면 유효합니다(로그 소멸 공격). 픽셀 유무로 프레임 수를 추정하지 않습니다.

## 저장 및 게임 반영

- `frames-v3/<직업>/idle-00.png` 등: 게임이 사용하는 독립 몸 프레임.
- 같은 이름의 `.fx.png`: 분리된 작은 효과. 없으면 완전 투명.
- `<직업>.aseprite`: Character / Local effect 레이어와 모션 태그가 있는 편집본.
- `<직업>-sheet.png`: 확인용 6열×5행 시트. **게임의 재분할 입력으로 사용하지 않습니다.**
- `frames-v3/manifest.json`: 파일 순서, 지속 시간, 고정 피봇.
- `source-v3/`: 이번 이관에 사용한 고해상도 원본과 재제작 공격 원본.
- `src/`: 기존 시트 및 다른 게임 리소스 보관. 기존 캐릭터 시트는 v3 빌드가 읽지 않습니다.

`python sprites/pack.py`는 v3 manifest가 있으면 독립 프레임을 검사하고 포장합니다.
아틀라스에는 셀 바깥으로 2px의 투명 간격을 두고, 정확한 사각형 좌표로 읽습니다.
몸 팔레트는 직업 전체에 공통으로 적용하며, 분리 효과에는 복장 색상 변경을 적용하지 않습니다.
편집본을 수정했다면 먼저 Aseprite 배치 실행으로 `sprites/export_frames.lua`를 실행해
PNG와 프레임 시간을 갱신합니다. 이 스크립트는 캔버스·레이어·여백을 함께 검사합니다.
이후 pack.py와 `python wrap.py`, `python wrap_site.py`로 실행 HTML을 갱신합니다.

`sprites/review.html`을 열면 직업 전체의 모션·정지 프레임·좌우 반전·기준선·효과를 확인할 수 있습니다.
검수 페이지가 비어 있으면 먼저 pack.py를 실행합니다.

## 기존 시트 이관과 앞으로의 편집

`prepare_frames.py`는 기존 고해상도 시트의 연결 영역을 추출할 좌표/마스크를 계산합니다.
`build_frames.lua`는 Aseprite에서 그 좌표를 사용해 픽셀을 추출합니다.
이 두 단계는 **최초 이관용**입니다. 이후 수동 수정한 프레임 위에 재실행하면 수정이 덮어써지므로,
일상 편집에서는 독립 PNG/편집본을 수정하고 pack.py만 실행합니다.
Lua의 root 매개변수는 sprites 폴더의 절대 경로이며 마지막 `/`를 포함합니다.

이번 이관의 발 위치는 원본에서 추정한 뒤 고정한 값입니다. 규격·여백 검사는 통과해도
원본 포즈 사이의 작화 차이까지 자동으로 매끈해지는 것은 아닙니다. 검수 페이지에서 어색한
프레임은 동일 피봇을 유지한 채 수작업으로 조정합니다.
프리스트/암흑사제의 서로 붙은 공격 포즈는 독립 포즈로 교체했으며, 발동 자세를 두 칸 유지합니다.

## 납품 체크

- 각 파일 256×256, 알파 0/255, 안전 여백 16px, 동일 피봇.
- 머리/몸/무기가 끊기지 않고 다른 프레임의 파편이 없음.
- 기본 자세에서 발 위치가 흔들리지 않음. 이동·점프는 의도한 움직임인지 확인.
- 공격의 준비/발동/회수가 연결되고, 오른쪽/왼쪽 방향 모두 정상.
- 원래 크기와 2배, 게임의 데스크톱/모바일 배치에서 확인.
- 검수한 개별 프레임만 시트/아틀라스로 포장.
