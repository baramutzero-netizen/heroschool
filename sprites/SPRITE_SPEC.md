# 스프라이트 제공 규격 (용사 학원)

## 1. 파일 형식
- **PNG, 인덱스 또는 32bit RGBA**
- **반투명 픽셀 금지** — 알파는 0 또는 255만. (128 미만은 전부 투명 처리됨)
- 배경 투명. 안티앨리어싱 없이 도트 그대로.
- 색 수 제한 없음. 단 전체 아틀라스 기준 256색 이내면 용량이 크게 줄어듭니다.

## 2. 시트 배치
한 직업 = PNG 파일 1장. 셀 크기 **128 x 128**, 패딩/여백 없음.
8프레임 x 5모션 = 시트 전체 **1024 x 640**.

| 행(row) | 모션 | 권장 프레임 | 재생 |
|---|---|---|---|
| 0 | idle (기본) | 2~4 | 무한 반복 |
| 1 | attack (공격) | 4~6 | 1회 후 idle 복귀 |
| 2 | hit (피격) | 2~3 | 1회 후 idle 복귀 |
| 3 | down (쓰러짐) | 3~5 | 1회 후 마지막 프레임 정지 |
| 4 | win (승리) | 3~4 | 무한 반복 |

- 프레임은 **각 행의 왼쪽부터 빈칸 없이** 채웁니다. 남는 칸은 완전 투명.
- 행마다 프레임 수가 달라도 됩니다. 빈 셀을 스캔해서 자동으로 개수를 셉니다.
- 행이 통째로 비어 있으면 idle 0번 프레임으로 대체합니다.
- 최대 8프레임. 더 필요하면 알려주세요.

## 3. 좌표 기준 (중요)
모든 프레임이 **같은 128x128 캔버스**를 씁니다. 프레임별 오프셋을 따로 주지 않습니다.

- 발바닥 기준선 **y = 106**. 착지 상태에서는 신발 밑이 여기에 닿습니다.
- 중심선 **x = 64**.
- 기준선 아래 21px, 위아래 여백은 무기 휘두름 / 점프 / 이펙트용으로 남겨둔 공간입니다.
- 캔버스를 넘어가면 잘립니다. 셀 안에서 해결해 주세요.
- 앞으로 파고들거나 뒤로 밀리는 이동은 프레임 안에서 캐릭터를 직접 옮겨 그리면 됩니다.

캐릭터 크기 자체는 자유입니다. 다만 **모든 직업이 같은 기준선과 중심선**을 쓰면
한 줄에 세웠을 때 발이 맞습니다.

## 4. 방향
**오른쪽(적을 향하는 방향)** 기준으로 한 벌만 그립니다.
상대 팀은 게임에서 좌우 반전(`scaleX(-1)`)해서 씁니다. 좌우 비대칭 장비가 있어도 그대로 반전됩니다.

## 5. 파일 이름
`<직업id>.png` — 게임 내부 id를 그대로 씁니다.

| id | 이름 | id | 이름 |
|---|---|---|---|
| paladin | 팔라딘 | wizard | 마법사 |
| sword | 소드맨 | druid | 드루이드 |
| monk | 몽크 | forcemage | 배틀메이지 |
| archer | 아쳐 | enchanter | 인챈터 |
| rogue | 로그 | darkpriest | 암흑 사제 |
| priest | 프리스트 | bard | 바드 |
| timemage | 타임 매지션 | spellsword | 마법검사 |
| gunner | 거너 | ninja | 닌자 |

몬스터(선택): `mon_dummy` `mon_wraith` `mon_gargoyle` `mon_brine` `mon_guardian`

파일 이름이 위 id와 달라도 아래 이름들은 자동으로 연결됩니다 —
`magician`·`mage`·`witch` → wizard, `swordman`·`swordsman` → sword, `knight` → paladin,
`thief`·`assassin` → rogue, `cleric` → priest, `hunter`·`ranger` → archer, `warlock` → darkpriest.
그 밖의 이름은 파일명 그대로 직업 id로 씁니다.

**머리색 자동 검출** — 캐릭터 상단 42% 안에 몰려 있으면서 색상(hue)이 서로 가까운 색들만
머리로 잡습니다. 피부·가죽·갑옷은 색상이 다르거나 아래쪽에 몰려 있어 제외됩니다.
머리와 같은 색을 다른 부위에도 쓰면 그 부위도 함께 바뀝니다 (마법사의 모자·로브처럼).

## 6. 전달 방법
`D:\heroschool\sprites\src\` 폴더를 만들어 그 안에 PNG를 넣어주세요.
제가 읽어서 하나의 아틀라스로 합치고 base64로 game.html 안에 박아 넣습니다.
(아트팩트로 배포되는 페이지는 외부 이미지 호스트를 막기 때문에 파일 링크로는 못 씁니다.)

채팅에 첨부해 주셔도 됩니다. 몇 장이든 한 번에.

## 7. 프레임 타이밍
기본값을 쓰고, 바꾸고 싶으면 알려주세요.

| 모션 | 프레임당 |
|---|---|
| idle | 180ms |
| attack | 70ms |
| hit | 90ms |
| down | 110ms (마지막 정지) |
| win | 150ms |

## 8. 적용 위치
- **전투 화면** — 턴마다 attack / hit / down 재생, 평소 idle
- **학생 카드 / 학적** — idle 반복
- **대회 대진표 / 팀 편성** — idle 0번 프레임 정지
- **졸업 / 진로 연출** — win 반복

## 9. 부분 제출 가능
전 직업을 한 번에 주실 필요 없습니다. 1개만 먼저 주시면 그걸로 전투 화면에 붙여서
움직이는 걸 확인한 뒤 나머지를 받는 쪽이 안전합니다.
스프라이트가 없는 직업은 자동으로 실루엣 플레이스홀더로 대체됩니다.

## 10. 용량
128x128 x 40칸 인덱스 PNG 한 장이 대략 8~20KB입니다.
21종 전부면 200~400KB. game.html 이 현재 420KB 라서 base64 로 박으면
1MB 근처가 됩니다. 넘칠 것 같으면 전투용 풀셋과 카드용 idle 셋을 분리하겠습니다.
