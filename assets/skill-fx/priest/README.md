# 프리스트 스타일리시 스킬 효과

투명 배경 단일 프레임 PNG. 캐릭터 애니메이션 시트와 별도 관리.

- essence.png: 시전자 직업 고유의 짙고 은은한 성스러운 에센스
- 신성 파동: paladin/impact.png 공용 성스러운 타격
- heal.png: 대치유의 연두 빛 입자
- blessing.png: 축복의 황금 세로 궤적
- revival.png: 부활의 기도의 작은 SD 천사와 하얀 입자

시전자 효과는 현재 직업, 대상 효과는 사용한 스킬을 기준으로 선택합니다. 부활한 아군도 효과 대상에 포함합니다.

공유 런타임: ../paladin/runtime.js. pack.py로 game.html에 반영 후 wrap.py 및 wrap_site.py 실행.

제작: 내장 image_gen. 생성 프롬프트는 prompts.md. 미리보기는 preview.html, 브라우저 검증은 check.cjs.
