# 도적(로그) 스킬 효과

- `dagger-embedded.png`: 독 단검(ro_1), 대상 복부에 초록 독날 단검.
- `shadow.png`: 그림자 밟기(ro_2), 대상 주변 푸른 세로 속도선. 현재 스킬은 self 대상이므로 시전자에게 표시.
- `assassinate.png`: 암살(ro_u), 대상 목 부근의 붉은 흩뿌림. 유지 시간 동안 전투 무대 전체 invert(1), 종료/취소 시 원래 필터 복원.

모두 별도 투명 단일 프레임 PNG. 직업 고유 효과는 이번 요청에 추가하지 않으며, 전수 시 대상 효과/색상 반전은 스킬 ID, 시전자 효과는 실제 직업을 따릅니다.
내장 image_gen 사용, 프롬프트는 `prompts.md`.
공용 코드 `../paladin/runtime.js` 수정 후 해당 폴더 `pack.py`, 루트 `wrap.py`, `wrap_site.py` 실행.
`check.cjs`: 두 빌드의 세 스킬/양쪽 방향/전수/반전 종료·취소 검증.

독 단검 수정: 기존 크기 0.48에서 0.34로 축소, 수평 삽입, 매몰된 칼날 끝 생략. 기존 원본 보관.
