# 바드 스타일리시 스킬 효과

투명 배경 단일 프레임 PNG. 캐릭터 시트와 별도 관리.

- melody.png: 현에서 흘러나오는 직업 고유 금빛 오선과 음표
- 진군가: ../rogue/shadow.png 재사용
- dissonance.png: 불협화음 붉은 세로 궤적
- ensemble.png: 승전의 합주, 자신과 대상 아군 머리 위를 잇는 푸른 오선과 황금 음표
- spotlight.png: 승전의 합주, 각 아군을 비추는 조명

공유 런타임 ../paladin/runtime.js에서 직업/스킬 효과를 분리 선택합니다. 합주는 아군 그룹 폭에 맞춰 표시되며, 시전자 중복을 제거합니다. 기본 공격 대상은 기존 타격 효과를 유지합니다.

제작: 내장 image_gen. prompts.md에 프롬프트 저장. preview.html은 실제 전투 미리보기. check.cjs는 로컬/사이트 빌드에서 기본 공격, 3개 스킬, 반대 방향, 전수 및 중단 정리를 검증합니다.

합주 선율은 원본 가로세로 비율을 유지한 구절을 겹쳐 연결합니다. 아군 배치 폭이 넓어져도 음표를 가로로 늘리지 않습니다.
