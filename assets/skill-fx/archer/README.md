# 아처 스타일리시 효과

투명 배경 단일 프레임 PNG, 캐릭터 시트와 별도 관리. 내장 image_gen 제작. prompts.md에 프롬프트 저장.
- wind.png: 직업 고유 녹색 바람
- pierce.png: 적 대열 전체를 관통하는 녹색 빛줄기, 그룹 효과 1개
- hawk-outline.png: 대상 머리 위 매 얼굴 선화
- meteor.png: 위쪽 경계선부터 단일 대상에게 집중되는 녹색 빛줄기

유성 화살은 피해 판정과 시네마틱 배치, 효과 모두 기존 후열 단일 대상에게 적용합니다. 관통 화살은 적 대열 높이를 맞춰 빛줄기가 전원을 통과하도록 표시합니다. 조준 사격 대상 효과는 기존 유지.

공유 런타임 ../paladin/runtime.js. preview.html 실제 전투 스크린샷. check.cjs 로컬/사이트 빌드의 좌우, 전수, 경계선 정렬, 그룹 인원 및 정리 검증.

빛줄기 수정: pierce-lines.png와 meteor-lines.png는 화살촉이 없는 연속 선입니다. 관통 화살은 시전자 앞에서 화면 바깥까지 연장합니다. 유성 화살은 시전자 쪽에서 12도 기울어져 위·아래 경계선을 모두 통과하며 단일 대상 중심을 지납니다.

관통 화살 최신 원본: pierce-offscreen.png. 지정된 화살 이미지의 앞쪽 25%가 화면 밖으로 나가도록 길이를 계산하며, 반대 진영에서는 좌우를 반전합니다.

관통 화살 시작점은 시전자 쪽에서 가장 가까운 첫 대상의 앞부분으로 맞춥니다. 반대 진영에서도 동일하게 반전 적용합니다.

유성 화살 최신 연출: meteor-perspective-back.svg(후경), meteor-perspective-front.svg(전경), meteor-impact.svg(복부 섬광). 화면 밖 상단 소실점에서 퍼지는 정지 벡터 빛줄기를 사용하며, 전투 경계선 안에만 녹색 암전을 표시합니다. 단일 대상 판정 유지, 종료/취소 시 레이어 제거.
