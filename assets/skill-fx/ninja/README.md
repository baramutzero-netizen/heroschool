# 닌자 스타일리시 효과

투명 배경 단일 프레임 PNG. 애니메이션 시트와 별도 관리.
- ripple.png: 닌자 직업 고유 발밑 물결, 학생 뒤 배경 바로 위
- swamp.png: 수둔·수렁의 적 그룹 바닥 늪, 반투명 및 학생 뒤
- 수렁의 붉은 궤적: ../bard/dissonance.png 재사용
- dragon.png: 노란 눈의 물 용머리 관통 타격
- fuma.png: 파도를 가르는 날 3개의 거대 수리검

공유 런타임 ../paladin/runtime.js. 시전자 효과는 직업, 대상 효과는 스킬 기준. 기본 쿠나이 대상 타격은 기존 효과 유지.
제작: 내장 image_gen. prompts.md에 생성 프롬프트, preview.html에 실제 전투 미리보기. check.cjs에서 로컬/사이트 빌드의 좌우 시전·전수·레이어·종료 정리를 검증.

## 관통 연출 수정
- 붉은 궤적: 닌자와 바드 모두 발 위치를 기준으로 위로 표시.
- boundary-wave.png: 아래 경계선에 발생하는 파도. 수룡은 여기서 대각선으로 대상을 관통.
- fuma-spin-blur.png: 개별 날이 보이지 않는 고속 회전 잔상. 낮은 타원 형태로 눕혀 적 뒤에 배치하고 회전.
- water-flower.png: 복부의 꽃 모양 관통 물보라.
- 기존 fuma.png와 fuma-passed.png는 이전 시안으로 보존.

풍마수리검 배치: 복부에서 뻗는 물줄기 끝에 물보라, 그 너머에 크게 기울어진 회전 잔상. 해당 스킬은 대상을 화면 중앙 쪽에 배치해 관통 이후 효과 공간을 확보합니다. 반대편 시전은 좌우 대칭.

현재 수리검 재질은 fuma-water-spin.png의 푸른 파도와 흰 포말입니다. 물줄기/파도 꽃(waterFlower) 역시 학생 뒤의 배경 바로 위 레이어로 이동했습니다. 배치, 크기, 회전 속도는 유지합니다.
