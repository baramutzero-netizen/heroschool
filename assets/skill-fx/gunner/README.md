# 거너 스타일리시 효과

- `muzzle.png`: 실제 직업이 거너일 때 앞으로 내민 한쪽 총구에만 표시. 반대 진영은 좌우 반전.
- `hit.png`: 가벼운 인사(gn_b), 속사 왈츠(gn_1)의 작은 흰색·금빛 타격과 주위 불꽃.
- `pierce.png`: 무례한 노크(gn_2), 그랜드 피날레(gn_u)의 대상 뒤로 퍼지는 관통 분사. 학생 뒤쪽 레이어 사용.
- 속사 왈츠는 전투 계산에서 기록한 `fx.shots` 순서대로 같은 단일 이미지를 재사용. 기본 4회, 중도 처치/대상 변경도 실제 기록을 따름. 배속에 맞춰 표시 간격 조절.
- 그랜드 피날레의 효과 유지 시간만 전투 무대 전체 흑백, 관통 입자는 어두운 실루엣. 종료·취소 시 원래 필터 복원.
- 전수 규칙 유지: 시전자 효과는 실제 직업, 대상 효과와 흑백 연출은 스킬 ID.

공용 연결 코드: `../paladin/runtime.js`. `../paladin/pack.py` 후 프로젝트 루트 `wrap.py`, `wrap_site.py`로 실행 파일 반영.
`check.cjs`: 양쪽 실행 파일의 4스킬, 실제 엔진 사격 기록, 순차 연타, 방향 반전, 일시정지 색상 복원, 전수 조합 검사.
내장 image_gen으로 제작. `prompts.md`에 프롬프트 저장. 모든 효과는 별도 투명 PNG 한 프레임.
