# 암흑 사제 직업 고유 효과

`essence.png`: 투명 단일 프레임. 캐릭터 주변을 감도는 보라색 에센스가 공격 3번째 프레임의 지팡이 끝으로 모입니다. 반대 진영에서는 좌우 반전됩니다.

시전자 실제 직업 `darkpriest`로 선택합니다. 전수한 스킬에도 적용되며, 대상 효과는 기존 스킬별 규칙을 유지합니다. 이번 변경은 직업 고유 효과만 추가합니다.

공용 연결 코드: `../paladin/runtime.js`. 해당 폴더의 `pack.py` 실행 후 프로젝트 루트의 `wrap.py`, `wrap_site.py`로 빌드합니다. 이미지 제작은 내장 image_gen 사용, 프롬프트는 `prompt.md`에 기록했습니다.

`check.cjs`: 두 실행 파일에서 양방향 시전, 전수 스킬 조합, 효과 로딩 및 정리 검증. `preview.html`: 실제 전투 캡처.

## 대상 효과 및 광역 효과
- dp_b: hit.png — 검푸른 타격
- dp_1: drain.png — 가슴에서 붉은 에센스 추출
- dp_2: nail.png — 가슴의 반투명 검푸른 대못
- dp_u: drain.png + ritual.png — 대상별 에센스 및 적 그룹 바닥 마법진/붉은 입자
- 공용 runtime의 groups 레지스트리는 스킬 ID로 광역 효과를 선택. fx.t 중 상대 진영만 그룹에 포함하며 한 번 표시. 시전자와 아군을 따로 배치하고 반대 진영일 때 좌우 반전.
- 검증: check-targets.cjs (양쪽 빌드/4스킬/반대진영/회복대상배치/광역대상 범위/정리). 생성 프롬프트: target-prompts.md.

광역 마법진과 입자는 불투명도 60%. 배경(z=-1) 바로 위(z=0)에 놓고, 카메라/학생 스태킹 컨텍스트보다 앞선 DOM 순서로 배치해 학생·이름·다른 효과 뒤에 표시합니다.
