# 학원 운영 일지 UI 목업

내장 image_gen으로 제작한 시각 방향 목업. 현재 게임 UI는 변경하지 않음.

## 방향
- 펼친 양피지 책을 기본 화면으로 사용. 왼쪽은 이번 주 계획과 생활 장면, 오른쪽은 학생 기록과 학원 소식.
- 일지·학생·시설·원정·기록 메뉴를 책 가장자리의 천 책갈피로 구성.
- 다음 주 진행은 ‘이번 주를 기록한다’라는 주요 동작으로 표현.
- 삽화와 필기 장식은 분위기를 만들되, 실제 구현의 본문과 수치는 선명한 글꼴로 표시.
- 날짜·자금·명성은 책 안쪽의 고정 위치에 유지. 많은 학생 정보는 학생 책갈피의 별도 페이지로 이동.
- 실제 UI 구현에서는 배경과 글자를 분리하여 수치 변화, 검색, 접근성, 반응형 화면을 지원해야 함.
