# 마법검사 V6 — 열혈의 축적

2026-10-15. 같은 2.5등신 프롬프트 컨셉의 새 시안. 두 눈을 감고 묵상하며 한 팔을 높이 들어 검지를 위로 세운다. 다른 손은 허리의 검 손잡이에 둔다. 고요한 집중 속에서 뜨거운 기운이 쌓이는 느낌이다.

내장 ImageGen 사용. resolve-character.png는 캐릭터 원화, resolve-aura.png는 별도 후광, pose-reference.png는 사용자 제공 손짓 참고, generation-prompts.txt는 생성 프롬프트다. preview.html에서 피격→기상→복귀를 확인하며 후광은 서서히 강해진다. 실제 게임 로직이나 최종 Aseprite 시트는 포함하지 않는다. 적용 전 픽셀 크기·알파·기준점 검수가 필요하다.

작업 공간과 D:/heroschool/tools/herospirit/heroic-resolve-spellsword-v6/에 함께 보관하며 기존 버전을 보존한다.

V6 변경: 기존 묵상 포즈를 기반으로 양쪽 신발을 브라운 가죽 장화로 변경했다. 후광과 발동 연출은 V4를 재사용한다. 내장 ImageGen 편집 사용. edit-prompt.txt에 수정 프롬프트를 보관한다.

V6 변경: 각 손은 엄지 포함 다섯 손가락이라는 조건으로 ImageGen에서 손 모양을 수정했다. 들어 올린 손은 검지를 펴고 나머지를 접으며, 아래 손은 검 손잡이를 잡는다. 가려진 손가락을 억지로 모두 펼치지 않는다. 두 눈을 감은 묵상 포즈와 브라운 장화를 유지했다. hand-edit-prompt.txt에 이번 편집 조건을 보관한다. 후광과 목업 연출은 이전 버전을 재사용한다.
