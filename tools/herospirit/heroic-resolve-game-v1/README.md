## 판정 (전투 계산 — 규칙 7 → 8)

- 의식 저하 선 아래에서 맞고 살아 있으면 한 번 굴린다: 0 ~ 기절 → 기절 · 기절 ~ 기절 + 기상 → 영웅의 기상 · 나머지 → 아무 일 없음.
- 학생만 (원정 몬스터 · 마왕은 예전 그대로). 학생의 기절 확률은 새 정신력 계수(정신력 1 → ×1.951 · 99 → ×0.307 · 같은 비율로 줄어든다).
  의식 저하로 줄어드는 스킬 위력은 예전 계수 그대로 (명부의 '의식 저하 경감' 도 그 값).
- 기상 확률은 체력과 상관없이 지구력 · 정신력 평균으로 5% → 20%. 학생마다 한 전투에 한 번 (쓰러졌다 부활해도 다시 없다) · 기상 상태인 동안은 굴리지 않는다.
- 기상 네 가지(무작위) — 불굴의 의지 공격력 +20% · 굳건한 신념 방어력 +20% · 맑아진 정신 명중 · 치명타 +10% · 샘솟는 용기 속도 +20%.
  전투가 끝날 때까지 · 쓰러지면 풀린다 (다른 효과와 같다). 화면에는 이름만 (늘어난 능력치 · '영웅의 기상' 이라는 말은 나오지 않는다).
- 반격(소드맨 반격 자세)으로 맞아도 같다.
- 기술 선택(①)은 전투 계산이 이미 하던 것(뜬 스킬 · 고른 스킬 · 이미 걸려 있어 그만둠 · 시전 실패 · 적에게 거는 스킬인지)을 프레임에 적어 보여 주기만 한다 (`frames[].pick` · 난수 순서 그대로).
- 전투 결과가 바뀌므로 규칙 번호 8 — 리그는 이번 시즌을 예전 규칙으로 연 사람에게 그 시즌 LP 를 주지 않는다.

## 연출 (넓은 화면 · 전투 연출 '스타일리시 모드')

- **① 기술 선택** — 행동 게이지가 찬 뒤 줌인 앞. 차례가 온 학생 머리 위에 상자 줄(기본기 + 스킬): 기본기는 바로 촥 · 스킬은 슬롯이 돌다 꽂힘(뜬 것) / 빨간 X(안 뜬 것) →
  하이라이트가 돌다 멈춤 (이미 걸려 있어 그만두면 기본기) → 시전 판정 (적에게 거는 스킬은 늘 · 아군 · 자신에게 거는 스킬은 실패할 때만 — RESIST / FAIL 딱지 → 기본기) →
  고른 상자만 남았다가 판째 사라지고 줌인. ×0.5 · ×1 은 기본, ×2 · ×3 은 압축. 몬스터 · 마왕 · 필살기는 바로 줌인.
  설정 '기술 선택 연출' — 모든 학생(기본) · 자신의 학생만 · 상대의 학생만 · 표시 안 함.
- **② 정신력 시험** — 맞는 순간을 조금 보인 뒤 시험받는 학생에게 천천히 다가간다 (주변 어둡게 · 다른 유닛은 숨김 · 두근두근 · 글 띠 '○○의 정신력이 시험받고 있습니다…') →
  기상: 하얗게 번쩍 · 뒤쪽 흐림 · 원화 + 후광 (도트 자리 크기의 1.5배 · 캐릭터 가운데가 전투판 높이의 59% · 줌아웃 전까지 1.07배로 천천히) · 반짝이 · 금빛 이름 /
  기절: 쓰러짐 · 흑백 · DOWN · '○○, 의식을 잃었다' → 줌아웃 → 본인 대사 → 같은 편 학생이 0.7초 간격으로 한마디씩 (기상 · 기절 따로).
  기상한 학생은 전투 끝까지 금빛 테 · 반짝이 · 별 칩 (칩 이름 = 기상 이름).
- 심플 모드 · 좁은 화면 — 금빛 이름이 떠오르고 금빛 테 · 별 칩 (원화 · 줌인 없음).
