# 게임 적용 V2 — 기절 두 번 쓰러짐 고침 · 전투 대사와 정신력 시험

2026-10-15 · 빌드 1015-1452 · 규칙 그대로 8. [V1](../heroic-resolve-game-v1/README.md)(빌드 1015-1321)을 고친 판 (V1 은 그대로 둔다). 원화 · 기상 이름 · 기상 · 기절 대사는 V1 과 같다.

## 고친 것 (사용자: '기절 체크가 발생해 쓰러지고 대사를 말한 다음 한번 더 쓰러지고 있어')

정신력 시험에서 기절한 학생은 시험 장면에서 이미 쓰러지고 줌아웃 뒤에도 누운 채 대사를 하는데, 차례가 끝나 전투 화면을 다시 그릴 때
쓰러짐 동작을 처음부터 다시 틀어 한 번 더 쓰러졌다 (그 차례에 쓰러진 학생은 다시 그릴 때 쓰러지는 모습을 트는 규칙 — 스타일리시는 몇 장씩 건너뛰므로).
이제 시험에서 쓰러지는 모습을 보인 학생은 다시 그려도 누운 채로 둔다 (game.html `camFell`).

## 같이 들어간 전투 대사와의 관계

같은 빌드에 스타일리시 전투 대사(선공 · 막타 · 첫 치명타 — `tools/gen/blines/`)가 들어갔다. 정신력 시험과 겹치는 곳:

- **첫 치명타를 맞고 버틴 대사**는 그 차례에 그 학생이 기절하거나 영웅의 기상이 나오면 나오지 않는다 (사용자: '살아남고, 기절하거나 영웅의 기상이 아닌 경우') —
  그때는 기상 · 기절 대사가 나오고, 버틴 대사는 그 학생이 다음에 치명타를 맞고 버틸 때로 미룬다.
- 줌아웃 뒤 순서: **첫 치명타 대사**(입힌 학생 → 맞고 버틴 학생, 0.55초 간격) → **기상 · 기절 대사** → 같은 편 반응.
- 반격(소드맨 반격 자세) 줄에서 치명타가 나와도 그 반격 줄까지 한 차례로 묶는다 (V1 은 정신력 시험이 나올 때만).
- 막타 차례(전투를 끝내는 차례)에는 치명타 대사를 하지 않는다.
