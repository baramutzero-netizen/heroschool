# 중국어 간체판 번역 지침 · 용어집 (1022)

중국어 간체 표(`tools/i18n/zh-Hans.json` · `tools/i18n/zh-Hans/*.json`)를 쓰거나 고칠 때 이 문서를 따른다. 표 규칙 자체(키 · 자리표 · 문맥 키)는 `tools/i18n/README.md` 와 같다.
일본어판(`ja/GUIDE.md`)과 같은 틀 — 다른 점은 표기 · 말투 · 용어.

- **한국어 → 중국어로 바로 옮긴다.** 영어 · 일본어 표는 짧은 UI 글의 뜻 · 쓰임을 확인할 때만 본다 — 그 문장 구조 · 줄임 · 말장난을 따라가지 않는다.
  (일본어 값은 '조사 자리를 뺀 자리표' · 'CJK 글자 폭에 맞춘 길이'의 좋은 본보기다.)
- 사용자는 중국어를 검수하지 못한다 → 자연스러운 중국 본토 게임 현지화 수준(简体 · 대륙 표현)으로, 원문의 뜻 · 정보 · 말투를 빠짐없이.
- 제목: **勇者学院养成记——学院倒闭了** (한국어 `용사 학원 키우기 — 학원이 망했다`). 짧게 쓸 때는 `勇者学院养成记`.
- 사용자 결정 (1022): 학생이 주인공을 부르는 말 **大师** — 주인공이 '모든 직업을 마스터한' 사람이라서(올마스터). 오프닝의 그 문장은 `全职业大师`.

## 1. 표 규칙 (값을 쓸 때)

- 키는 game.html 의 한국어 원문 그대로 — **절대 고치지 않는다** (띄어쓰기 · 앞뒤 빈칸 · 문장부호 하나까지). 값만 중국어로.
- `{0}` `{1}` … 자리표: 중국어 어순에 맞게 옮겨도 된다. 값에 쓰는 자리표는 키에 있는 것만.
  - **조사 자리는 쓰지 않는다** — `iga(…)` · `eunn(…)` · `gwa(…)` · `eulr(…)` · `ro(…)` · `jo(…)` 가 채우는 자리(이/가 · 은/는 · 과/와 · 을/를 · 으로/로 …).
    어느 자리가 조사인지는 일본어 값을 본다 (일본어 값이 쓰지 않은 자리 = 조사 자리) · 또는 `python3 tools/i18n/unit_ctx.py '키'` 의 `조사 자리`.
    예: `{0}{1} 승리했다` ({1} = `iga({0})`) → `{0}获胜了`.
  - 그 밖의 자리(이름 · 숫자 · 앞뒤 조각)는 모두 쓴다. 빠뜨리면 정보가 사라진다. **작업 칸의 `keep` 자리표 목록과 같은 모음이어야 한다.**
- `{who}` · `{job}` · `{who+이}` · `{who+을}` · `{when}` 같은 이름 자리: 이름은 그대로 두고 조사 꼬리(`+이` 등)는 뗀다 — `{who}`.
- 태그: 키에 있는 태그(`<b>` `<i>` `<small>` `<span>` `<br>` …)를 값에도 같은 수로. 차례를 바꿀 때만 `<b#2>`(원문의 두 번째 b). 속성은 쓰지 않는다.
  `&ldquo;` 같은 HTML 글자는 중국어 문장부호로 바꿔도 된다.
- 단수 · 복수 `{0|a|b}` 는 쓰지 않는다.
- `∅` = 중국어에서는 빈 글. 거의 쓰지 않는다 — 한국어 조각이 붙는 곳도 중국어 조각이 있으면 옮긴다 (예: `d + "요일"` 의 `요일` → 앞뒤 맞춰 `周` 쪽으로).
- 문맥 키 `맨위선언|원문` 은 일본어 · 영어 표와 같은 키를 그대로 옮긴다. 중국어에서 뜻이 갈리는 곳이 더 있으면 문맥 키를 새로 더해도 된다.
- 앞뒤 빈칸: 키의 앞뒤 빈칸은 코드가 앞뒤 글과 이을 때 쓰는 것. 중국어는 띄어쓰기가 없으니 필요 없으면 뺀다 (` 용사 학원` → `勇者学院` · ` 등` → `等`).
  단 숫자 · 라틴 글자와 붙어서 읽기 어려워지면 남긴다.
- 값에 한글을 남기지 않는다. 곧은 따옴표 `"` 도 쓰지 않는다. 일본어 가나도 쓰지 않는다 (일본어 값을 베끼지 않는다).
- **번체자 · 일본 한자를 쓰지 않는다** — 모두 간체 (学 · 战 · 剑 · 术 · 师 · 书 · 气 · 灵 · 龙 · 门 · 听 · 说 …). 일본어 값의 한자(戦 · 剣 · 術 · 黒 · 鉄 · 気 · 楽 · 図 · 鑑)를 그대로 옮기지 않는다.

## 2. 표기

| 무엇 | 중국어 |

| 문장부호 | 전각 `，` `。` `！` `？` `：` `；` `、`. 한국어 `!` `?` 도 문장 안에서는 `！` `？` |
| 괄호 | 문장 · 설명은 전각 `（ ）`. 숫자 · 기호만 든 짧은 칸(`(+{0}G)` · `({0}/{1})`)은 반각 `( )` 그대로 |
| 나열 | 문장 속 나열은 `、` (`가, 나, 다` → `甲、乙、丙`). UI 칸 · 능력치 줄의 ` · ` 는 `·` (빈칸 없이 — `攻击力·速度`) |
| 줄표 | 한국어 ` — ` → `——` (U+2014 두 개 · 앞뒤 빈칸 없음). 제목 · 이름표 사이도 같다 |
| 말줄임 | `……` (U+2026 두 개). 한국어 `...` · `…` · `..` → `……` (아주 짧은 칸 · 끊긴 외침은 `…` 하나도 된다) |
| 대사 따옴표 | 한국어 “ ” → **“ ”** 그대로 (간체 표준). 대사 안의 인용 · 강조(‘ ’)도 ‘ ’ |
| 그 밖의 인용 · 이름 강조 | 한국어 ‘ ’ → “ ” (대사 안이면 ‘ ’). 코드가 짝을 맞추는 곳(전투 외침 `‘크큭… ` — 끝의 ’ 는 코드)은 ‘ 를 남긴다 |
| 이명(称号) | `「不屈之壁」高文` 처럼 「 」 — 이름과 붙인다 (빈칸 없음 · 코드가 붙인다). 이명 값 자체에는 「」 를 쓰지 않는다 |
| 책 · 글 이름 | 《 》 (드물다) |
| 숫자 | 반각 숫자 · `,` 그대로. `+` `-` `−` `×` `%` 도 키 그대로 반각 |
| `%p` | 중국어는 `%` 로 (확률 · 비율이 더해지는 것 — 게임 관례) |
| 단위 | `{0}명` → `{0}人` · `{0}회` → `{0}次` · `{0}개` → `{0}个` · `{0}장`(카드) → `{0}张` · `{0}주` → `{0}周` · `{0}주차` → `第{0}周` · `{0}학년` → `{0}年级` · `{0}년차` → `第{0}年` · `{0}턴` → `{0}回合` · `{0}라운드` → `第{0}轮`(목록 칸은 `{0}轮`) · `{0}승 {1}패` → `{0}胜{1}负` · `{0}위` → `第{0}名` · `{0}구간` → `第{0}段` · `{0}일` → `{0}天` · `{0}곳`(학원) → `{0}所` · `{0}세트` → `{0}局` · `G` 그대로 |
| 요일 | 월 화 수 목 금 → 一 二 三 四 五 (칸에 혼자 쓰일 때) · `{0}요일` → `周{0}` |

## 3. 말투

모든 학생은 **성별이 없다** (이름 · 초상만). 중국어는 3인칭 대명사가 성별을 드러내므로 —
**学生을 他 · 她 로 부르지 않는다** (이름 · `这名学生` · `对方` · `那孩子` · 생략 · 글말에서는 `其`). `TA` 도 쓰지 않는다.
`学长` · `学姐` · `兄弟` · `姐妹` · `小伙子` · `姑娘` · `少年` · `少女` 처럼 성별이 든 말도 학생에게 쓰지 않는다 (선배 · 후배 · 동기 → `前辈` · `后辈` · `同期`).
1인칭 `我` 는 성별이 없어 그대로. 학생은 마스터를 `大师` 라 부르고, 한국어가 존댓말(해요체 · 합니다체)이면 `您`, 반말이면 `你`.

| 성격 키 | 한국어 | 중국어 이름 | 중국어 말투 |
|---|---|---|---|
| intro | 소심 | 内向 | 머뭇거리고 더듬는다. `那、那个……` `……是。` `好、好的……` `对不起……` 한국어의 `……` 를 살린다 |
| hot | 열혈 | 热血 | 씩씩하고 크게, `！` 가 많다. `是！` `燃起来了！` `我不会输的！` `交给我吧！` |
| stone | 차분 | 冷静 | 짧고 딱딱하다. 분석적 · 감정 표현 적음. 어기 조사(呀 · 啦 · 嘛 · 哦)를 쓰지 않는다. `明白了。` `判断完毕。` `没有问题。` `理解。` |
| dilig | 성실 | 认真 | 공손하고 열심. `是！` `我会努力的！` `谢谢您！` `请交给我。` |
| tsun | 새침 | 傲娇 | 퉁명 + 속마음은 다정. `……哼。` `才、才不是为了您呢。` `别误会了。` `随便您。` 한국어가 반말이면 `你` · `才不是为了你` |
| lively | 활발 | 活泼 | 밝고 감탄이 많다. `嘿嘿` `哇——` `～哦！` `～啦！` `～呢！` |
| boast | 허세 | 中二 | 거창하고 연극적 (중2 느낌). 1인칭은 가끔 `吾`(성별 없음 — `本大爷` · `老子` 는 쓰지 않는다). `身为英雄……` `不愧是大师！` `此乃吾之宿命！` 전투 외침은 `呵呵呵……` `将此景烙印在你眼中吧！` |
| plain | 평범 | 平凡 | 평범하고 공손 |
| genius | 천재적 | 天才型 | 담담하고 조금 건방짐. `果然如我所料。` `计算早就做完了。` `～对吧？` `这种程度的话。` |

- **마스터(주인공 · 아버지의 아들)**: 학생에게는 단호하지만 따뜻한 말 (`去吧。` `做得好。` `相信我。` `你们`). 1인칭 `我`.
  아버지에게는 아들의 말 (`爸！` `我会的。`). 오프닝 · 프롤로그의 1인칭 서술(나)도 `我`.
- **아버지**: 기운 없는 아버지의 말 (`……孩子啊。` `你`).
- **서술(나레이션 · 학원 일지 · 이야기 팝업 · 상담의 반응 글)**: 담담한 글말 (`……了。` `……着。`). 지나치게 고어 · 문어(`之乎者也`)는 쓰지 않는다.
- **화면 설명 · 툴팁 · 안내**: 짧은 설명문. 한국어가 `~한다/~된다` 면 `……。` 서술, `~하세요/~합니다` 면 `请……` · `将……`.
  단추 · 메뉴 이름은 짧은 명사나 동사 (`关闭` `继续` `购买` `确定`).
- **마을 사람 · NPC**: 밭주인 할아버지 — 시골 노인 말투 가볍게 (`老头子我` `～啊` `～呗`) · 교회 수녀 — 상냥한 존댓말 (`请` `呢`) · 여관 안주인 — 시원시원한 아주머니 (`～啦！` `快去快回！`) ·
  사냥꾼 · 주점 주인 — 무뚝뚝한 반말 (`～吧。` `懂了吗？`) · 미용실 원장 — 친근한 말투 (`～呢` `～哦`) · 은행장(行长) — 정중한 업무 말투 (`本行` `贵学院`) ·
  상인 · 상점 주인 — 장사꾼 말투 (`欢迎光临！` · 한국어가 그만큼 공손할 때만 `您`).
- **1년차 암흑 사제(`uniq: dp1`)**: 마스터를 `‘大师’` 로 부른다 (한국어 `‘마스터’` — 코드 `masterQ` 가 중국어도 맞춘다 · 값에 `‘大师’` 로 쓴다).
- **마왕 · 오프닝의 적**: 고풍스러운 악역 (1인칭 `吾` · 상대를 `汝` / `你` · 웃음 `哼哼哼……` `呵哈哈哈……`). 오프닝의 신비한 여인: 엄숙하고 정중 (`托付给你了。`).
- 감탄사 · 의성어는 중국어 것으로 (헤헤 → 嘿嘿 · 흥 → 哼 · 크큭 → 呵呵 · 우오옷 → 呜哦哦 · 으아 → 呜哇 · 쿨럭 → 咳咳 · 냠 → 啊呜 · 휴 → 呼).

## 4. 이름

- **학생 이름(`NAME_POOL|…`)**: 중국어 표준 음역(신화사 외래 인명 표기)을 따른다. 원래 이름(유럽 이름 등)이 분명하면 그 이름의 중국어 관례 —
  `가웨인` → `高文` · `롤랑` → `罗兰` · `아르튀르` → `阿蒂尔`(프랑스식) · `미카엘` → `米迦勒` · `소피아` → `索菲亚` · `엘레인` → `伊莲`.
  2 ~ 4자 · 흔한 음역 글자. **두 한국어 이름이 같은 중국어가 되면 안 된다** (세이브를 한국어로 되돌릴 때 하나로 정해져야 한다).
- **한국식 성 · 이름(`SUR|…` · `GIV|…`)**: 예전 세이브에만 남는 것. 한자로 (`김` → `金` · `이` → `李` · `박` → `朴` · `도윤` → `道允`). 성과 이름은 빈칸 없이 붙는다(런타임).
  역시 서로 겹치지 않게.
- **학원 이름 조각(`ACAD|…`)**: 한자어는 간체 한자로 (`백은` → `白银` · `흑철` → `黑铁` · `청람` → `青岚`), 고유어 · 외래어는 뜻으로 (`잿빛탑` → `灰塔`).
  런타임이 `○○勇者学院` · `○○学院` 으로 붙인다 (빈칸 없음) — 조각은 2 ~ 3자.
- **NPC 학원(`L5_NPC_ACAD|…`) · 몬스터(`MON|…`)**: 뜻을 살려 옮긴다 (`왕립 근위 학원` → `王立近卫学院`).
- **이명(称号)**: 짧고 멋있게 — 4자 안팎 (`불굴의 성벽` → `不屈之壁` · `여명의 수호자` → `黎明守护者`). 서로 겹치지 않게.
- **유물 이름(`RELIC_ADJ|…` · `RELIC_NOUN|…`)**: 런타임이 `형용사+명사` 를 빈칸 없이 붙인다 → 형용사는 2자 꾸밈말로 바로 붙게 (`은빛` → `银色` · `낡은` → `破旧`) · 명사도 2자 안팎 (`반지` → `戒指`) — `银色戒指` · `破旧戒指`. `的` 는 넣지 않는다.
- 신화 · 전설의 이름은 중국어 관례 (`엑스칼리버` → `王者之剑` · `묠니르` → `妙尔尼尔` · `브리싱가멘` → `布里希嘉曼` · `아이기스` → `埃癸斯` · `슬레이프니르` → `斯雷普尼尔`).

## 7. 일하는 법 (Claude)

- 단위가 어디서 어떻게 쓰이는지 모르겠으면 코드를 본다 — 맨 위 선언 · 줄 · 자리표 식. 짧은 단추 · 칸 글은 화면 폭이 좁다 — **한국어 글자 수를 크게 넘지 않게** (중국어는 한국어보다 대개 짧다 · 일본어 값보다 길면 다시 본다).
- 빌드 끝 줄 `중국어 … 중국어 글꼴에 없는 글자` 가 0 이 아니면 그 글자를 쉬운 글자로 바꾸거나 `python3 tools/gen/fonts/zh_fonts.py FONTSRC` 로 글꼴을 다시 만든다.
- 표를 고치면 `zh_fonts.py` 를 다시 돌린다 — 도트 글꼴은 GB2312 전부라 거의 그대로지만, 허세 말풍선 · 오프닝 글꼴은 표 · SC_ZH 에 쓰인 글자만 넣었다.
- 중국어 화면 점검: `python3 tools/i18n/check_layout.py --lang zh-Hans` (빌드 뒤) · 세이브 왕복 `python3 tools/i18n/check_save.py --lang zh-Hans`.
