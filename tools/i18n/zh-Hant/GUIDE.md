# 중국어 번체판(대만) 번역 지침 · 용어집 (1022)

중국어 번체 표(`tools/i18n/zh-Hant.json` · `tools/i18n/zh-Hant/*.json`)는 **간체 표에서 만든다** — 손으로 고치지 않는다.

    python3 tools/i18n/zh_work.py hant          간체 표 → 번체 표 (OpenCC s2twp + 아래 대만 관례 + 손본 값 zh-Hant_fix.json) · pip: opencc
    python3 tools/i18n/zh_work.py export ui --lang zh-Hant --out a.jsonl      검토 칸 (sc = 간체 값 · zh = 지금 번체 값)
    python3 tools/i18n/zh_work.py fix ui a.tsv --lang zh-Hant                  고친 값(번호<TAB>번체)을 zh-Hant_fix.json 에 → hant 를 다시
    python3 tools/i18n/zh_work.py check --lang zh-Hant                         자리표 · 태그 · 한글 · 가나 · 곧은 따옴표 · Big5 밖 글자

- 순서: 간체 표를 먼저 고친다 (뜻 · 말투 · 정보는 간체판 지침 `zh-Hans/GUIDE.md` 가 기준) → `hant` → 번체에서만 다른 것(대만 말 · 글자)은 `zh-Hant_fix.json`.
  손본 값은 그때의 간체 값과 같이 남는다 — 간체 값이 바뀌면 `hant` 가 '다시 볼 손본 값' 으로 알려 주고 새로 옮긴 값을 쓴다.
- 대상: **대만 표준(正體 · 台灣用語)**. 홍콩 · 마카오 브라우저도 이 판을 본다 (번체 지역 zh-TW · zh-HK · zh-MO · zh-Hant).
- 제목: **勇者學院養成記——學院倒閉了** (짧게 `勇者學院養成記`). 학생이 주인공을 부르는 말 **大師** · 오프닝 `全職業大師`.
- 사용자는 중국어를 검수하지 못한다 → 대만 게임 현지화 수준으로 자연스럽게.

## 1. 표 규칙

간체판 지침 1장과 같다 (키는 그대로 · 자리표 · 조사 자리 · 태그 · `∅` · 문맥 키 · 앞뒤 빈칸 · 한글 · 가나 · 곧은 따옴표 금지). 다른 점:

- **글자**: 대만 교육부 표준 자형 · **Big5 안**의 번체자. 간체자 · 일본 한자(戦 · 剣 · 黒 · 気 · 楽 · 図 · 鉄)를 쓰지 않는다.
  게임 글꼴은 12px 도트 (Fusion Pixel 번체 — Big5 1급 + 표에 쓰인 글자) — 너무 어려운 글자는 쉬운 말로.

## 3. 말투

모든 학생은 **성별이 없다** (이름 · 초상만). 중국어는 3인칭 대명사가 성별을 드러내므로 —
**學生을 他 · 她 로 부르지 않는다** (이름 · `這名學生` · `對方` · `那孩子` · 생략 · 글말에서는 `其`). `TA` 도 쓰지 않는다.
`學長` · `學姐` · `兄弟` · `姐妹` · `小夥子` · `姑娘` · `少年` · `少女` 처럼 성별이 든 말도 학생에게 쓰지 않는다 (선배 · 후배 · 동기 → `前輩` · `後輩` · `同期`).
1인칭 `我` 는 성별이 없어 그대로. 학생은 마스터를 `大師` 라 부르고, 한국어가 존댓말(해요체 · 합니다체)이면 `您`, 반말이면 `你`.

| 성격 키 | 한국어 | 중국어 이름 | 중국어 말투 |
|---|---|---|---|
| intro | 소심 | 內向 | 머뭇거리고 더듬는다. `那、那個……` `……是。` `好、好的……` `對不起……` 한국어의 `……` 를 살린다 |

| stone | 차분 | 冷靜 | 짧고 딱딱하다. 분석적 · 감정 표현 적음. 어기 조사(呀 · 啦 · 嘛 · 哦)를 쓰지 않는다. `明白了。` `判斷完畢。` `沒有問題。` `理解。` |

- **마스터(주인공 · 아버지의 아들)**: 학생에게는 단호하지만 따뜻한 말 (`去吧。` `做得好。` `相信我。` `你們`). 1인칭 `我`.
  아버지에게는 아들의 말 (`爸！` `我會的。`). 오프닝 · 프롤로그의 1인칭 서술(나)도 `我`.
- **아버지**: 기운 없는 아버지의 말 (`……孩子啊。` `你`).
- **서술(나레이션 · 학원 일지 · 이야기 팝업 · 상담의 반응 글)**: 담담한 글말 (`……了。` `……著。`). 지나치게 고어 · 문어(`之乎者也`)는 쓰지 않는다.
- **화면 설명 · 툴팁 · 안내**: 짧은 설명문. 한국어가 `~한다/~된다` 면 `……。` 서술, `~하세요/~합니다` 면 `請……` · `將……`.
  단추 · 메뉴 이름은 짧은 명사나 동사 (`關閉` `繼續` `購買` `確定`).
- **마을 사람 · NPC**: 밭주인 할아버지 — 시골 노인 말투 가볍게 (`老頭子我` `～啊` `～唄`) · 교회 수녀 — 상냥한 존댓말 (`請` `呢`) · 여관 안주인 — 시원시원한 아주머니 (`～啦！` `快去快回！`) ·
  사냥꾼 · 주점 주인 — 무뚝뚝한 반말 (`～吧。` `懂了嗎？`) · 미용실 원장 — 친근한 말투 (`～呢` `～哦`) · 은행장(行長) — 정중한 업무 말투 (`本行` `貴學院`) ·
  상인 · 상점 주인 — 장사꾼 말투 (`歡迎光臨！` · 한국어가 그만큼 공손할 때만 `您`).
- **1년차 암흑 사제(`uniq: dp1`)**: 마스터를 `『大師』` 로 부른다 (한국어 `‘마스터’` — 코드 `masterQ` 가 중국어도 맞춘다 · 값에 `『大師』` 로 쓴다).
- **마왕 · 오프닝의 적**: 고풍스러운 악역 (1인칭 `吾` · 상대를 `汝` / `你` · 웃음 `哼哼哼……` `呵哈哈哈……`). 오프닝의 신비한 여인: 엄숙하고 정중 (`託付給你了。`).
- 감탄사 · 의성어는 중국어 것으로 (헤헤 → 嘿嘿 · 흥 → 哼 · 크큭 → 呵呵 · 우오옷 → 嗚哦哦 · 으아 → 嗚哇 · 쿨럭 → 咳咳 · 냠 → 啊嗚 · 휴 → 呼).

## 4. 이름

- **학생 이름(`NAME_POOL|…`)**: 중국어 표준 음역(신화사 외래 인명 표기)을 따른다. 원래 이름(유럽 이름 등)이 분명하면 그 이름의 중국어 관례 —
  `가웨인` → `高文` · `롤랑` → `羅蘭` · `아르튀르` → `阿蒂爾`(프랑스식) · `미카엘` → `米迦勒` · `소피아` → `索菲亞` · `엘레인` → `伊蓮`.
  2 ~ 4자 · 흔한 음역 글자. **두 한국어 이름이 같은 중국어가 되면 안 된다** (세이브를 한국어로 되돌릴 때 하나로 정해져야 한다).
- **한국식 성 · 이름(`SUR|…` · `GIV|…`)**: 예전 세이브에만 남는 것. 한자로 (`김` → `金` · `이` → `李` · `박` → `樸` · `도윤` → `道允`). 성과 이름은 빈칸 없이 붙는다(런타임).
  역시 서로 겹치지 않게.
- **학원 이름 조각(`ACAD|…`)**: 한자어는 간체 한자로 (`백은` → `白銀` · `흑철` → `黑鐵` · `청람` → `青嵐`), 고유어 · 외래어는 뜻으로 (`잿빛탑` → `灰塔`).
  런타임이 `○○勇者學院` · `○○學院` 으로 붙인다 (빈칸 없음) — 조각은 2 ~ 3자.
- **NPC 학원(`L5_NPC_ACAD|…`) · 몬스터(`MON|…`)**: 뜻을 살려 옮긴다 (`왕립 근위 학원` → `王立近衛學院`).
- **이명(稱號)**: 짧고 멋있게 — 4자 안팎 (`불굴의 성벽` → `不屈之壁` · `여명의 수호자` → `黎明守護者`). 서로 겹치지 않게.
- **유물 이름(`RELIC_ADJ|…` · `RELIC_NOUN|…`)**: 런타임이 `형용사+명사` 를 빈칸 없이 붙인다 → 형용사는 2자 꾸밈말로 바로 붙게 (`은빛` → `銀色` · `낡은` → `破舊`) · 명사도 2자 안팎 (`반지` → `戒指`) — `銀色戒指` · `破舊戒指`. `的` 는 넣지 않는다.
- 신화 · 전설의 이름은 중국어 관례 (`엑스칼리버` → `王者之劍` · `묠니르` → `妙爾尼爾` · `브리싱가멘` → `布里希嘉曼` · `아이기스` → `埃癸斯` · `슬레이프니르` → `斯雷普尼爾`).

## 7. 일하는 법 (Claude)

- 번체 표를 직접 고치지 않는다 — 간체 표를 고치고 `zh_work.py hant` · 대만에서만 다른 것은 `zh_work.py fix` (검토 칸 번호) → `hant`.
- 표를 고치면 `python3 tools/gen/fonts/zh_fonts.py FONTSRC --lang zh-Hant` 도 다시 (허세 말풍선 · 오프닝 글꼴은 쓰인 글자만 · 빌드 끝 줄의 `글꼴에 없는 글자`).
- 화면 점검 `python3 tools/i18n/check_layout.py --lang zh-Hant` · 세이브 왕복 `python3 tools/i18n/check_save.py --lang zh-Hant` · 글꼴 · CSS `python3 tools/i18n/check_zh.py`.
