# 일본어판 번역 지침 · 용어집 (1014)

일본어 표(`tools/i18n/ja.json` · `tools/i18n/ja/*.json`)를 쓰거나 고칠 때 이 문서를 따른다. 표 규칙 자체(키 · 자리표 · 문맥 키)는 `tools/i18n/README.md` 와 같다.

- **한국어 → 일본어로 바로 옮긴다.** 영어 표(`en/*.json`)는 짧은 UI 글의 뜻을 확인할 때만 본다 — 영어의 문장 구조 · 줄임 · 말장난 · 이름 고르기를 따라가지 않는다.
- 사용자는 일본어를 검수하지 못한다 → 자연스러운 일본 게임 현지화 수준으로, 원문의 뜻 · 정보 · 말투를 빠짐없이.
- 제목: **わが英雄のアカデミー ― 学園がつぶれた** (한국어 `용사 학원 키우기 — 학원이 망했다` · 영어 `My Hero's Academy`).
  타자기 제목 · 로딩 화면처럼 짧게 쓸 때는 `わが英雄のアカデミー`.

## 1. 표 규칙 (값을 쓸 때)

- 키는 game.html 의 한국어 원문 그대로 — **절대 고치지 않는다** (띄어쓰기 · 앞뒤 빈칸 · 문장부호 하나까지). 값만 일본어로.
- `{0}` `{1}` … 자리표: 일본어 어순에 맞게 옮겨도 된다. 값에 쓰는 자리표는 키에 있는 것만.
  - **조사 자리는 쓰지 않는다** — `iga(…)` · `eunn(…)` · `gwa(…)` · `eulr(…)` · `ro(…)` · `jo(…)` 가 채우는 자리(이/가 · 은/는 · 과/와 · 을/를 · 으로/로 …). 일본어 조사(が · は · と · を · で · に)를 값에 직접 쓴다.
    어느 자리가 조사인지는 `python3 tools/i18n/unit_ctx.py '키'` 의 `조사 자리` 를 본다. 예: `{0}{1} 승리했다` ({1} = `iga({0})`) → `{0}が勝利した`.
  - 그 밖의 자리(이름 · 숫자 · 앞뒤 조각)는 모두 쓴다. 빠뜨리면 정보가 사라진다.
- `{who}` · `{job}` · `{who+이}` · `{who+을}` · `{when}` · `{next}` 같은 이름 자리: 이름은 그대로 두고 조사 꼬리(`+이` 등)는 뗀다 — `{who}が` · `{who}を`.
- 태그: 키에 있는 태그(`<b>` `<i>` `<small>` `<span>` `<br>` …)를 값에도 같은 수로. 차례를 바꿀 때만 `<b#2>`(원문의 두 번째 b). 속성은 쓰지 않는다 (키에도 없다).
  `&ldquo;` 같은 HTML 글자는 일본어 문장부호로 바꿔도 된다 (`&ldquo;{1}&rdquo;` → `「{1}」`).
- 단수 · 복수 `{0|a|b}` 는 쓰지 않는다 (일본어에 필요 없다).
- `∅` = 일본어에서는 빈 글. 거의 쓰지 않는다 — 한국어 조각이 붙는 곳도 일본어 조각이 있으면 옮긴다 (예: `d + "요일"` 의 `요일` → `曜日`).
- 문맥 키 `맨위선언|원문` 은 영어 표와 같은 키를 그대로 옮긴다. 일본어에서 뜻이 갈리는 곳이 더 있으면 문맥 키를 새로 더해도 된다 (키 = 그 단위의 맨 위 선언 이름 + `|` + 원문 — `unit_ctx.py` 의 `[ ]` 안).
- 앞뒤 빈칸: 키의 앞뒤 빈칸은 코드가 앞뒤 글과 이을 때 쓰는 것. 일본어는 띄어쓰기가 없으니 이을 때 필요 없으면 뺀다 (` 용사 학원` → `勇者学園` · ` 등` → `など`).
  단 이름 · 숫자와 붙어서 읽기 어려워지면 남긴다.
- 값에 한글을 남기지 않는다. 곧은 따옴표 `"` 도 쓰지 않는다.

| 말줄임 | `……` (두 개) 또는 `…` — 한국어에 맞춘다. `...` → `…` |

## 3. 말투

모든 학생은 **성별이 없다** (이름 · 초상만). 일본어 말투도 성별이 드러나지 않게 —
1인칭은 되도록 빼고, 필요하면 `私`. `俺` `僕` `あたし` · 끝의 `わ` `のよ` `ぜ` `ぞ` 는 학생 대사에 쓰지 않는다 (아래 성격별 예외만).
학생은 마스터를 `マスター` 라고 부르고, 마스터에게는 한국어가 존댓말(해요체 · 합니다체)이면 です・ます.

| 성격 키 | 한국어 | 일본어 이름 | 일본어 말투 |
|---|---|---|---|
| intro | 소심 | 内気 | 머뭇거리는 です・ます. `あ、あの……` `……はい` 말을 더듬는다 (`わ、わかりました……`). 한국어의 `……` 를 살린다 |
| hot | 열혈 | 熱血 | 씩씩하고 큰 です・ます (한국어 합니다체). `！` 가 많다. `はいっ！` `燃えてきました！` `負けません！` |
| stone | 차분 | クール | 딱딱하고 짧은 です・ます. 분석적 · 감정 표현 적음. 줄임 말투(`～じゃない` `～てる`) 없이 `～ではありません` `～しています`. `判断します` `理解しました` |
| dilig | 성실 | 真面目 | 공손하고 열심인 です・ます. `はい！` `がんばります` `ありがとうございます` |
| tsun | 새침 | ツンデレ | 퉁명한 です・ます + 속마음은 다정. `…別に` `…ふん` `～ですけど` `勘違いしないでください`. 전투 외침처럼 한국어가 반말이면 반말(`勘違いしないで`) |
| lively | 활발 | 活発 | 밝은 です・ます + 감탄. `えへへ` `うわあ` `～ですよ！` `～しちゃいました` |
| boast | 허세 | ビッグマウス | 거창하고 연극적인 です・ます (중2 느낌). `英雄たる者～` `さすがはマスター！` `この私が～`. 전투 외침은 `くっくっ…` `その目に焼き付けろ` |
| plain | 평범 | 平凡 | 평범한 です・ます |
| genius | 천재적 | 天才肌 | 담담하고 조금 건방진 です・ます. `予想どおりですね` `計算は済んでいます` `～ですよね？` |

- **마스터(주인공 · 아버지의 아들)**: 학생에게는 반말 — 단호하지만 따뜻한 常体 (`～しろ` `～しよう` `～だ` `～てこい`). 1인칭은 되도록 빼고 필요하면 `俺`.
  아버지에게는 아들의 반말 (`父さん！` `～だよ` `～するよ`). 오프닝 · 프롤로그의 1인칭 서술(나)도 `俺` (되도록 뺀다).
- **아버지**: 기운 없는 아버지의 반말 (`～だ` `～か` `お前`).
- **서술(나레이션 · 학원 일지 · 이야기 팝업 · 상담의 반응 글)**: 한국어 해라체 → 일본어 常体 (`～した` `～だ` `～る`). 문어체 `～である` 는 쓰지 않는다.
- **화면 설명 · 툴팁 · 안내**: 한국어가 `~한다/~된다` 면 常体 (`～する` `～される`), `~하세요/~합니다` 면 です・ます (`～してください` `～します`).
  단추 · 메뉴 이름은 짧은 명사나 동사 (`閉じる` `進める` `購入`).
- **마을 사람 · NPC**: 밭주인 할아버지 — 노인 말투 가볍게 (`わし` `～じゃ` `～でな`) · 교회 수녀 — 상냥한 존댓말 · 여관 안주인 — 시원시원한 아주머니 (`～だよ` `～おくれ`) ·
  사냥꾼 · 주점 주인 — 무뚝뚝한 반말 (`～だ` `～な`) · 미용실 원장 — 친근한 여성 말투 (`～わね` 괜찮다) · 은행장(頭取) — 정중한 비즈니스 경어 ·
  상인 · 상점 주인 — 장사꾼 경어 (`いらっしゃいませ` `～でございます` 는 한국어가 그만큼 공손할 때만).
- **1년차 암흑 사제(`uniq: dp1`)**: 마스터를 `『マスター』` 로 부른다 (한국어 `‘마스터’` — 코드 `masterQ` 가 일본어도 맞춘다).
- **마왕 · 오프닝의 적**: 고풍스러운 악역 (`貴様` `～だ` `～か`). 오프닝의 신비한 여인: 엄숙하고 정중한 문어 (`～よ` 로 부르는 말 · `～です` `～ください`).
- 대사의 감탄사 · 의성어는 일본어 것으로 (헤헤 → えへへ · 흥 → ふん · 크큭 → くっくっ · 우오옷 → うおおっ · 으아 → うわあ · 쿨럭 → ごほっ · 냠 → もぐ).

## 4. 이름

- **학생 이름(`NAME_POOL|…`)**: 가타카나. 한국어 표기의 발음을 따르되, 원래 이름(유럽 이름 등)이 분명하면 그 언어의 일본 관례 표기로 —
  `가웨인` → `ガウェイン` · `롤랑` → `ローラン` · `아르튀르` → `アルテュール`(프랑스식 — 영어식 アーサー 아님) · `미카엘` → `ミカエル` · `소피아` → `ソフィア`.
  장음은 `ー`. 두 한국어 이름이 같은 가타카나가 되면 안 된다 (세이브를 한국어로 되돌릴 때 하나로 정해져야 한다).
- **한국식 성 · 이름(`SUR|…` · `GIV|…`)**: 예전 세이브에만 남는 것. 한국어 발음 가타카나 (`김` → `キム` · `도윤` → `ドユン`). 성과 이름 사이 `・` 는 런타임이 붙인다.
- **학원 이름 조각(`ACAD|…`)**: 한자어는 일본 한자로 (`백은` → `白銀` · `흑철` → `黒鉄` · `청람` → `青藍`), 고유어 · 외래어는 뜻이나 가타카나로 (`잿빛탑` → `灰の塔`).
  런타임이 `○○勇者学園` · `○○学園` 으로 붙인다 (빈칸 없음).
- **NPC 학원(`L5_NPC_ACAD|…`) · 몬스터(`MON|…`)**: 뜻을 살려 옮긴다 (`왕립 근위 학원` → `王立近衛学園`).
- **이명(二つ名)**: 짧고 멋있게 — `불굴의 성벽` → `不屈の城壁` · `여명의 수호자` → `黎明の守護者`. 서로 겹치지 않게.
- **유물 이름(`RELIC_ADJ|…` · `RELIC_NOUN|…`)**: 런타임이 `형용사+명사` 를 빈칸 없이 붙인다 → 형용사는 뒤에 명사가 바로 와도 되는 꼴로 (`은빛` → `銀色の` · `낡은` → `古びた`).
- 신화 · 전설의 이름은 일본 관례 (`엑스칼리버` → `エクスカリバー` · `묠니르` → `ミョルニル`).

## 7. 일하는 법 (Claude)

- 단위가 어디서 어떻게 쓰이는지 모르겠으면 코드를 본다 — 맨 위 선언 · 줄 · 자리표 식. 짧은 단추 · 칸 글은 화면 폭이 좁다 (한국어 길이를 크게 넘지 않게).
- 빌드 끝 줄 `일본어 … 일본어 글꼴에 없는 글자` 가 0 이 아니면 그 글자를 쉬운 한자 · 가나로 바꾸거나 `tools/gen/fonts/ja_fonts.py` 로 글꼴을 다시 만든다.
- 일본어 화면 점검: `python3 tools/i18n/check_ja.py` (빌드 뒤).
