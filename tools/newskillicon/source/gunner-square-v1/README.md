# 거너 투명 스킬 아이콘
2026-10-15

- 가벼운 인사 (일반공격): greeting
- 앙코르는 기본이죠 (패시브): encore
- 속사 왈츠 (스킬): waltz
- 무례한 노크 (스킬): knock
- 그랜드 피날레 (필살기): finale

게임 스킬 정의 확인 후 내장 ImageGen으로 투명 원화 생성.
90% canvas fill, 96×96 논리 픽셀 스타일, 투명 배경, 테두리 없음.
은색 총신, 금색 금속 장식, 자주색 나무 손잡이와 청록 보석을 공통 디자인으로 지정.
Aseprite에서 알파 경계 여백 정리 후 비율 유지하여 긴 쪽 86px(89.6%)로 중앙 배치하고 최근접 샘플링으로 96×96 출력.
원본 색상과 알파 보존, RGB 모드 사용. 전체 픽셀 수작업 재묘사는 아님.
파일: *-original.png, *-prompt.txt, *-96.aseprite, *-96.png, *-4x.png.
빈 투명 캔버스와 심볼 레이어 분리. 게임에는 미적용.
