# 바드 투명 스킬 아이콘

2026-10-15

- 현 튕기기 (일반공격): pluck
- 합주 (패시브): harmony
- 진군가 (스킬): march
- 불협화음 (스킬): dissonance
- 승전의 합주 (필살기): victory

게임 스킬 정의를 확인하고 내장 ImageGen으로 각 투명 원화를 생성.
프롬프트에서 90% canvas fill, 96×96 논리 픽셀 스타일, 투명 배경, 테두리 없음을 명시.
Aseprite에서 알파 경계 여백 정리 후 비율 유지하여 긴 쪽 86px(89.6%)로 중앙 배치하고 최근접 샘플링으로 96×96 출력.
원본 색상과 알파 보존, RGB 모드 사용. 전체 픽셀 수작업 재묘사는 아님.
파일: *-original.png, *-prompt.txt, *-96.aseprite, *-96.png, *-4x.png.
빈 투명 캔버스와 심볼 레이어 분리. 게임에는 미적용.
