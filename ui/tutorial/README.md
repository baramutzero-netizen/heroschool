# 반응형 운영 안내 12종

`runtime.js`의 설명과 `style.css`의 배치가 편집 원본입니다. 게임에서는 글자를 이미지 안에 굽지 않고 HTML로 표시합니다. PC에서는 2열, 640px 이하에서는 1열이며 본문은 16px입니다. 긴 페이지는 세로로 읽고 하단의 44px 이상 버튼은 고정됩니다. 도트 폰트의 24px 일괄 확대 대상에서 `tg-` 규칙을 제외합니다.

기존 12개 주제 키와 `tutOnePage`, `tutOverPage`, `showTutorial`의 해금·콜백을 유지합니다. 원본 `assets/tut_img`는 보존하며 현재 팝업은 `tutGuideHTML`을 사용합니다. 현재 카드 렌더러·표식·멘탈리티·연속 훈련·라이벌 배율·개인 행동 정의를 읽기만 하며 게임 난수를 소비하지 않습니다.

현재 규칙 반영: 개인 행동 4종, 약점 자동 훈련, 라이벌 공동 훈련, 첫 시내 대회 이후 증축 개방, 마스터 노트 메뉴명. 가상의 전체 화면 스크린샷 대신 기능을 확대해 보여 주는 안내 도식을 사용합니다.

빌드: 프로젝트 루트에서 `python ui/tutorial/pack.py`, `python wrap.py`, `python wrap_site.py`.

검증·PNG 갱신: Playwright가 설치된 Node로 `node ui/tutorial/check.cjs`. 실행용과 배포용 파일, 320·390·1200px, 기본·일지 테마, 12종 안내, 첫 안내 종료·다시 보기·겹침 팝업 콜백을 검사합니다. 임시 브라우저 컨텍스트를 사용하며 온라인 요청을 차단합니다.

`assets/tutorial-v2/01.png`~`12.png`: 390 CSS px 세로형 안내를 2배 해상도로 출력한 780px 너비 PNG. `preview.html`에서 전부 볼 수 있습니다. 원본 UI와 기존 캐릭터 자산을 브라우저로 렌더링했으며 새 AI 이미지 생성은 사용하지 않았습니다. PNG는 검토·공유용이고 게임에서는 반응형 원본을 표시합니다.
