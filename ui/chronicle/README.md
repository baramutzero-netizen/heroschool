# 진행 페이지 테스트 모드

설정 → 진행 페이지 테스트 모드 → 사용. 기본 false. 브라우저 PREF에 저장되며 게임 저장 및 기존 일정 규칙은 그대로 사용한다.

- 기존 책 목업을 image_gen으로 빈 양피지 배경으로 편집. book-source.png 원본, book.webp 최적화본, game.html에 인라인 포함.
- runtime.js: 기존 viewPlanClassic에서 실제 버튼/손패를 가져와 새 진행 화면 구성. 5일 일정, 동일 카드 클릭·포인터/HTML 드래그 배치 및 회수, 색상·체인·표식, 예지의 서 구입/사용 연결.
- 학생은 3열 × 최대 5행, 15명씩 페이지 이동. 얼굴/이름/컨디션/집중 목표, 기존 일괄 설정과 휴식 전환 연결.
- 진행은 빈 인장 → 승인 도장 연출 → 기존 runWithReport. 시즌 말/빈 슬롯 등 기존 비활성 조건 유지.
- 학생·시설 책갈피는 기존 페이지로 이동. 다른 탭은 기존 화면 유지.
- 작은 화면은 양피지 2쪽을 세로 배치, 모션 감소 설정에서는 도장 대기를 생략.
- preview.html: 실제 저장 데이터와 격리된 체험 화면. 학생 18명 버튼 지원.

빌드: pack.py → ../../wrap.py → ../../wrap_site.py. pack.py는 현재 game.html의 관련 지점만 수정한다.
검사: check.cjs. 클릭 배치/회수, HTML 드래그, 포인터 드래그, 18명 명부, 집중 목표, 자동 배치, 책갈피, 설정 저장, 모바일 너비, 도장 후 실제 경과 보고 확인.

배경 제작 프롬프트: 기존 chronicle-ui.png의 책 모양, 양피지, 책상, 조명과 제본은 유지하되 페이지의 모든 글자·인물·삽화·선·인장·버튼·책갈피를 제거. HTML 정보를 얹을 수 있도록 두 페이지를 밝고 빈 양피지로 제작. 내장 image_gen 사용.

## 장식 및 서체 개선
- 학원 문장 + ‘학원명 운영 일지’, 장식 구분선과 날짜 밑줄.
- 좌측 격언과 우측 상단 메모, 잎사귀가 붙은 계획/손패/개인 집중 훈련 제목.
- 전체 훈련 종류에 대응하는 삽화 (강화 훈련은 해당 계열 삽화 공유), 요일 사이 잉크 선.
- 자금 옆 돈주머니와 좌측 하단 편지.
- 로컬 Nanum Pen Script와 Nanum Brush Script. 외부 폰트 접속 없이 배포본에서도 표시.
- prepare-ornaments.py → pack.py → 루트 wrap.py → wrap_site.py 순서. 서체와 이미지가 바뀌지 않으면 prepare 단계 생략.
- check-ornaments.cjs: 이미지 디코딩, 글꼴 로드, 긴 학원명, 18명, 태블릿 및 모바일 폭 확인.
